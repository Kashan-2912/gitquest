# GitQuest Roadmap

## Done
- AI creature generation from a GitHub profile (Google Gemini)
- Contribution tiers from CR 0 to CR 20+
- Leaderboard and public user profiles
- GitHub README widget (SVG) with the tagline API route
- Dark and light mode

## Next
- Leaderboard ranked by creature tier and contribution criteria
- Richer creature stats and share cards
- More monster art styles

## Later ideas
- Seasonal events and limited creatures
- Guilds: compare a whole team or organisation in one view
- Public API for the widget data

Have an idea? Open a feature request issue.
