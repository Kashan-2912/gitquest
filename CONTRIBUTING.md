# Contributing to GitQuest

Thanks for helping build GitQuest.

## Set up
1. Fork the repo, then clone your fork.
2. Run `npm install`.
3. Copy `.env.example` to `.env.local` and add your own keys.
4. Run `npm run dev`.

## Make a change
1. Make a branch from `main`, e.g. `feat/short-name` or `fix/short-name`.
2. Keep one change per branch.
3. Run `npm run lint` and `npm run build` before you push.
4. Open a pull request to `main` and fill in the PR template.

## Rules
- Never commit `.env.local` or any real key.
- Keep pull requests small and easy to review.
